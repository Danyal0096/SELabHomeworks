# Software Engineering Lab — Homeworks

This repository contains the coursework, source code, and documentation for the **Software Engineering Lab** course. Each experiment is organized in its own directory so its implementation, evidence, and report can be reviewed independently.

## Experiments

| No. | Experiment | Focus | Status |
| --- | --- | --- | --- |
| 01 | Git and Continuous Deployment | Version control, branches, pull requests, merge conflicts, GitHub Actions, and GitHub Pages | Not started |
| 02 | Object-Oriented Design | SOLID principles, refactoring, and assisted development with OpenCode | Not started |
| 03 | Test-Driven Development | Java unit testing, Red–Green–Refactor, code coverage, and mutation testing | Not started |
| 04 | Behavior-Driven Development | Behavioral scenarios, Scenario Outlines, and step definitions | Not started |
| 05 | Docker Fundamentals | Dockerfiles, Docker Compose, container networking, and port forwarding | Not started |

## Repository structure

Experiment directories will be added as work begins:

```text
SELabHomeworks/
├── README.md
├── Experiment1/
├── Experiment2/
├── Experiment3/
├── Experiment4/
└── Experiment5/
```

Each experiment directory will contain its relevant source files and a README documenting the work, execution instructions, and required deliverables. Additional files will be included where an experiment calls for them.

## Tools and technologies

The coursework involves **Git and GitHub**, **HTML/CSS/JavaScript**, **Java and its testing tools**, **OpenCode**, and **Docker**. Specific dependencies and setup instructions will be documented in the corresponding experiment directories.

## Submission notes

Experiment 1 uses GitHub features for its version-control and deployment workflow. Experiment 3 also specifies submission through a public **Hamgit** repository; any experiment-specific submission links will be documented when available.
